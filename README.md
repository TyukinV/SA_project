#  Система бронирования отелей (Hotel Booking System)
### *Портфельный проект по системному анализу*

Добро пожаловать в репозиторий, демонстрирующий мой подход к системному анализу и проектированию сложных информационных систем. 
Данный проект представляет собой **полный цикл анализа** для платформы бронирования отелей — от сбора бизнес-требований до архитектурных решений и контрактов на интеграцию.

---

##  1. Контекст и проблематика

В современном гостиничном бизнесе управление номерным фондом сталкивается с рядом критических вызовов:

- **Овербукинг (Double-booking):** Ошибки ручного бронирования или отсутствие транзакционной изоляции приводят к продаже одного номера двум гостям одновременно, что наносит репутационный урон.
- **Динамическое ценообразование:** Стоимость номера зависит от десятков факторов (сезон, день недели, длина проживания, загрузка отеля), и удержание этих правил в Excel-таблицах приводит к потере прибыли.
- **Долгий цикл подтверждения:** Отсутствие четкого BPMN-процесса затягивает согласование заявок на бронирование между менеджерами.
- **Разрозненность данных:** Информация о гостях, платежах и инвентаре хранится в разных системах без четкой модели данных.

**Цель проекта:** Создать концептуальную основу для автоматизированной системы, которая исключает человеческий фактор в критических операциях и обеспечивает масштабируемость.

---

##  2. Цели и задачи проекта

-  Разработать **функциональные и нефункциональные требования** (SRS / FRS) к MVP системы.
-  Смоделировать бизнес-процессы с использованием нотации **BPMN 2.0** (процесс бронирования, заезда/выезда, отмены).
-  Спроектировать **UML-диаграммы** различных уровней: Use Cases, Sequence, State Machine и ERD.
-  Разработать **API-контракты** для интеграции с внешними платежными шлюзами и системами турагенств.
-  Создать **матрицу трассировки требований (RTM)**, обеспечивающую полную прослеживаемость от бизнес-пожеланий до атрибутов в базе данных.
-  Обосновать ключевые архитектурные решения (ADR) для обработки конкурентных запросов.

| Категория | Технологии / Инструменты |
| :--- | :--- |
| **Язык реализации** | Java 17 / Spring Boot (Backend), React / TypeScript (Frontend) |

| **Документирование API** | OpenAPI 3.0 / Swagger (YAML) |
| **Управление версиями** | Git / GitHub |
